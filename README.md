## Commands
Here are the current commands and the way to use them. <br>

### echo
echo prints a message of your choice <br>

```sh
echo <message>
```
The echo command cannot print spaced sentences because the argument system thinks there is a second argument :( <br>

### Easter Egg
porpos is to print the string "Porpos is cool!!!!!!!!!!!!" and is not used in any serious context. <br>

```sh
porpos
```
### cat
cat returns the content of the file of your choice. <br>

```sh
cat <file name>
```

### touch
touch creates a file containing the string of your choice. <br>

```sh
touch <file name> <contents>
```
